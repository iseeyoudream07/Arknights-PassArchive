# Web 端代码可读性

- 新写或修改的源码应合理换行、按层级缩进，避免把整段代码压在一行。
- HTML 和 TypeScript 中的 HTML 模板字符串使用 4 个空格表示一层缩进；不同的结构标签、并列元素分行书写，长属性列表逐项换行。
- 短的行内标签可以与相邻文字保留在同一行；换行时保留有意义的空格，避免改变文本显示和页面布局。
- JavaScript / TypeScript 的语句和分支按结构换行；CSS 的声明逐项换行。保留必要的中文说明，便于阅读、调试和编辑。
- 排版修改保留现有文案、元素 ID、事件绑定和业务行为；先检查用户已有修改，避免覆盖。
- 此约定用于源码。第三方 `src/vendor/` 代码和自动生成的 `dist/` 文件不做无关的批量格式化。
